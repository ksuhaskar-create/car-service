# Бриф проекта: Учёт технического обслуживания автомобиля
## 1. Общие сведения
**Название продукта:** CarTrack 

**Краткое описание:** CarTrack - это сайт, где можно вести историю обслуживания автомобиля, записывать расходы и следить за состоянием машин.

**Целевая аудитория:** Автовладельцы, которые хотят контролировать расходы на машину и не забывать вовремя менять расходники (масло, фильтры, колодки).

## 2. Функциональные требования
**Обязательные (MVP):**
1. Пользователь может выбирать один из трёх заранее заданных автомобилей: Skoda Octavia A5, Lada Priora 2011 или BMW M5.
2. Пользователь может просматривать историю обслуживания выбранного автомобиля.
3. Пользователь может добавлять записи об обслуживании и ремонте, указывая дату, пробег, описание работ и стоимость.
4. Программа автоматически подсчитывает общие расходы на выбранный автомобиль.
5. Пользователь может добавлять запчасти к записи обслуживания, указывая название, количество и цену.
6. Программа отображает напоминание о замене масла на основе текущего пробега и пробега последней замены масла.

## 3. Нефункциональные требования
*   **Язык интерфейса:** Русский.
*   **Производительность:** Время отклика интерфейса — не более 1 секунды при стандартных операциях.
*   **Хранение данных:** Локально в файле БД (SQLite), сеть не используется.
*   **Защита от ошибок:** Нельзя сохранить запись ТО с отрицательным пробегом или стоимостью; нельзя удалить запчасть, если она используется в записях (без подтверждения).
*   **Инициализация БД:** При первом запуске приложение само создает таблицы из встроенного SQL-скрипт

## 6. Сценарии использования (Use Cases)

**Сценарий 1: Добавление записи о ТО для Skoda Octavia A5**
*   **Актер:** Пользователь
*   **Предусловие:** В системе добавлен автомобиль Skoda Octavia A5 и есть справочник запчастей.
*   **Основной поток:**
 1. Пользователь нажимает «Добавить запись».
2. Система открывает форму.
3. Пользователь вводит дату 12.10.2026, пробег 200.000, тип работ «Замена масла», стоимость работ 1500 руб.
4. Пользователь добавляет запчасть «Масло моторное» — 4 шт., цена 800 руб., и «Масляный фильтр» — 1 шт., цена 500 руб.
5. Пользователь нажимает «Сохранить».
6. Система сохраняет запись, запчасти и обновляет общую сумму расходов для Skoda Octavia A5.
*   **Альтернативный поток:** Если пробег меньше предыдущего значения (например, пользователь ввел 240000, а прошлая запись была 245000), система выдает предупреждение, но позволяет сохранить (например, если пользователь ошибся ранее).

**Сценарий 2: Просмотр истории по узлу (Замена масла) для Skoda Octavia A5**
*   **Актер:** Пользователь
*   **Предусловие:** В базе есть минимум 2 записи о замене масла для Skoda Octavia A5.
*   **Основной поток:**
1. Пользователь выбирает в фильтре тип работ «Замена масла».
2. Система отображает только записи с этим типом для выбранной машины.
3. Пользователь видит даты и пробеги замен (например, 245000 км и 250000 км), может оценить интервалы.
*   **Альтернативный поток:** Если записей нет, система выводит «Нет записей по данному фильтру».

**Сценарий 3: Проверка напоминаний для Skoda Octavia A5**
*   **Актер:** Пользователь
*   **Предусловие:** В базе есть записи о замене расходников для Skoda Octavia A5.
*   **Основной поток:**
1. Пользователь открывает вкладку «Напоминания».
2. Система берет последнюю запись по каждому типу работ, вычитает её пробег из текущего общего пробега автомобиля (например, текущий 255000, последняя замена масла была на 250000).
3. Если разница превышает заданный порог (например, 10000 км), система подсвечивает пункт красным: «Масло: 5000 км назад — пора менять».
*   **Альтернативный поток:** Если пробег не введен, система запрашивает его для расчета.
