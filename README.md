# CarTrack - учёт технического обслуживания автомобиля

Учебный проект: сайт, где можно вести историю обслуживания автомобиля, записывать расходы на работы и запчасти и получать напоминание о замене масла.

## Возможности

- Выбор одного из трёх автомобилей: Skoda Octavia A5, Lada Priora 2011, BMW M5. У каждой машины своё фото и своя цветовая тема.
- История обслуживания выбранного автомобиля: дата, пробег, работы, запчасти, стоимость.
- Добавление записи с запчастями (название, количество, цена).
- Автоматический подсчёт расходов: работы плюс запчасти по каждой записи и общий итог по машине.
- Напоминание о замене масла: если с последней замены прошло 10 000 км или больше, показывается красное предупреждение «Пора менять масло!».
- Проверка данных: нельзя сохранить запись с пустым описанием, без даты, с отрицательными числами или с нулевым количеством запчастей.
- Данные хранятся в локальной базе SQLite и сохраняются после перезапуска. При каждом запуске делается резервная копия базы (последние 10 копий лежат в папке `backups`).

## Технологии

Python, Flask, SQLite (модуль `sqlite3`), HTML и CSS.

## Как запустить

1. Установите Python 3.10 или новее.
2. Установите Flask: `pip install -r requirements.txt`
3. Запустите сайт одним из способов:
   - двойным щелчком по файлу `Запустить CarTrack.bat` (Windows), браузер откроется сам;
   - командой `python app.py` в папке проекта, затем откройте в браузере `http://127.0.0.1:5000`.

При первом запуске таблицы в базе создаются автоматически из файла `init.sql`, добавляются три автомобиля. Файл базы `cartrack.db` появится в папке проекта сам.

Чтобы остановить сайт, закройте окно с сервером или нажмите `Ctrl+C`.


## Как работает напоминание о масле

- Заменой масла считается запись, в описании которой есть слово «масло» (в любой форме: «замена масла», «Масло и фильтр»).
- Текущий пробег - это наибольший пробег среди записей автомобиля.
- Если разница между текущим пробегом и пробегом последней замены масла не меньше 10 000 км, показывается предупреждение. Иначе - сколько километров осталось.

## База данных

Три таблицы со связями «один ко многим»:

- `cars` - автомобили;
- `service_records` - записи об обслуживании (связаны с `cars` по `car_id`);
- `parts` - запчасти (связаны с `service_records` по `service_record_id`).

Схема описана в файле `init.sql`, ER-диаграмма лежит в репозитории (файл «4 модель данных.png»).
