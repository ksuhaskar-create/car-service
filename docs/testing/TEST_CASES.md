# Тест-кейсы приложения CarTrack

До фактического запуска статус всех проверок — **Не выполнен**. Наличие тест-кейса не означает, что функция уже проверена.

## Реестр функций

| ID | Функция | Уровень проверки |
|---|---|---|
| F-01 | Выбор автомобиля | Интерфейс |
| F-02 | Просмотр истории | Интерфейс, БД |
| F-03 | Добавление обслуживания | Интерфейс, БД |
| F-04 | Добавление запчастей | Интерфейс, БД |
| F-05 | Расчёт расходов | Бизнес-логика, интерфейс |
| F-06 | Напоминание о масле | Бизнес-логика, интерфейс |
| F-07 | Инициализация и повторный запуск | Приложение, БД |
| F-08 | CRUD таблицы `cars` | SQL/SQLite |
| F-09 | CRUD таблицы `service_records` | SQL/SQLite |
| F-10 | CRUD таблицы `parts` | SQL/SQLite |

> CRUD-проверки выполняются отдельными SQL-запросами к тестовой БД. Они не означают, что в интерфейсе есть функции добавления, изменения или удаления автомобилей, записей и запчастей.

## 12. Итог выполнения

После фактического тестирования указывается один из статусов:
- **Пройден** — фактический результат совпал с ожидаемым.
- **Не пройден** — результат отличается от ожидаемого.
- **Не выполнен** — проверка ещё не проводилась.
- **Не реализован** — необходимой функции или метода нет в текущей версии.
- **Не применим** — проверка не относится к возможностям текущей версии.

Нельзя отмечать тест как пройденный до его реального выполнения.
