Запуск проверки:
1. Открыть терминал в папке cartrack_task7.
2. Выполнить: python "$env:USERPROFILE\OneDrive\Desktop\CarTrack\cartrack_task7_ready\cartrack_task7\test_logic.py"

Тесты используют временную базу и не изменяют рабочую базу сайта.
